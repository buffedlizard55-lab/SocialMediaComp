# SocialMediaComp

Competition-style leaderboard of high-reach social accounts and communities, with **cited sources** for every row.

Live site (after GitHub Pages is enabled): `https://buffedlizard55-lab.github.io/SocialMediaComp/`

## What this is
- 20 entries (TikTok, Instagram, Reddit) in `data/master-list.json`
- Official education links and observed patterns in `data/strategies.json`
- Static GitHub Pages UI: `index.html`

## What this is not
- Not live follower counts
- Not proof of organic vs paid growth
- Not a how-to for buying engagement

## Verify
Open each `source_url` and `profile_url` in the JSON. Wikipedia and Visual Capitalist are secondary lists.
